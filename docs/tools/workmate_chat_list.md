# workmate_chat_list

List the stateful 1C:Workmate conversations this EDT currently remembers, most recently updated first. Read-only. Chats live in EDT's memory and are lost when EDT restarts - an empty list after a restart is expected, not an error.

## Parameters
| Parameter | Required | Type | Description |
| --- | --- | --- | --- |
| limit | — | integer | Optional maximum number of chats to return; omit to return every remembered chat (at most 50). |

## Guide
Lists the stateful 1C:Workmate conversations this EDT currently remembers, most recently
updated first. Read-only.

Chats live in EDT's memory and are lost when EDT restarts - an empty list after a restart is
expected, not an error.

## Example

```json
{}
```

Result:

```json
{
  "success": true,
  "chats": [
    {
      "chatId": "2d3f...",
      "title": "Refactoring research",
      "projectName": "MyConfiguration",
      "turns": 4,
      "hasSessionCursor": true,
      "sendInFlight": false,
      "lastTurnStatus": "done",
      "hasUnread": true,
      "createdAtMillis": 1760000000000,
      "updatedAtMillis": 1760000600000
    }
  ]
}
```

- `sendInFlight: true` means a `workmate_chat_send` is still running - poll its jobId with
  `get_job_status` instead of sending again.
- `lastTurnStatus` is `"none"` (fresh chat), `"running"` (send in flight), `"done"` (last turn completed), or `"failed"` (last turn failed).
- `hasUnread: true` means a turn finished (`done` or `failed`) since the last `workmate_chat_history` call on this chat.
