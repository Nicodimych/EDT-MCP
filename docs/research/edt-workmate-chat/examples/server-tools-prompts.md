# Тексты для следующей контролируемой проверки

Это prompts, не автоматически запускаемые тесты. Сохранить фактические tool_call_id, имена, статусы, размер результата и окончательный текст. Не экспортировать reasoning, credentials или полный текст статьи ИТС.

## Точный web fetch — ещё не подтверждён через внешний native цикл

Выполни именно доступный серверный инструмент mcp__web__fetch для https://example.com/. Верни название вызванного инструмента и заголовок страницы из фактического результата. Не используй WebSearch, ИТС, knowledge-hub, Task, TodoWrite или локальные инструменты. Если инструмент недоступен, сообщи об этом. Ничего не изменяй.

## ИТС — аналог успешно проверенного сценария

Используй mcp__knowledge-hub__Fetch_ITS для https://its.1c.ru/db/utovio/content/97/hdoc. Назови фактический заголовок документа и кратко изложи два положения. Если доступа нет, так и сообщи. Не выполняй локальные инструменты и ничего не изменяй.

## Вопрос пользователя — только текстовая часть

Сначала спроси меня, какой объект конфигурации исследовать, и дождись ответа. Пока не запускай инструменты и ничего не изменяй.

Сам по себе такой prompt проверяет текстовый обмен. Для structured interaction нужен фактический нативный event/карточка, а не разбор текста модели эвристикой.
